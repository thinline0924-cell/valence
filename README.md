# VALENCE

原子をつなぎ、反応を連鎖させる化学反応パズルです。スマホの縦画面を主に、パソコンでも遊べます。

ブラウザで動く静的サイトです(HTML・CSS・JavaScript と three.js だけ)。インストールやビルドは要りません。

## 遊び方

- **置く**:マスを押すと、次の原子が置かれ、となりの原子とつながります。つなぐ順番は自由です
- **完成**:つながった原子の組み合わせが実在の物質と同じになると、その姿(気泡・しずく・結晶など)に変わります。もっと大きな物質になれるときは、0.9秒待ってから完成します
- **反応**:となり合った物質は、条件がそろうと反応します。生成物がさらに反応すると連鎖になり、その間は時計が止まります(1回の連鎖で最大8秒)
- **熱**:発熱反応で熱がたまります。加熱マスでは、たまった熱を使って吸熱反応を起こせます。満タンになると過熱になり、反応が速くなって得点が2倍になります
- **核**:反応を9回起こすと、ウランが出はじめます。ウランに酸素を2つつなげると燃料です。燃料を2マス以内に2つ置き、水に接すると核分裂し、中性子が近くの燃料に届いて連鎖します
- **特殊なマス**:加熱(燃焼の点火、吸熱反応)、光、触媒
- **回す**:盤を横にドラッグするか、右下の ‹ › ボタンで、60°ずつ回せます
- **中断**:右下の「中断」(パソコンでは Esc か P)で一時停止。再開・やり直し・やめるを選べます

制限時間は2分30秒です。結果はランキングに記録できます(全員で共有するには `docs/ranking.md` の設定が必要)。

## 手元で動かす

`index.html` をダブルクリックで直接開くと、ブラウザの安全のしくみ(ES モジュールの制限)で動きません。Web サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## Render で公開する

1. https://dashboard.render.com で **New +** → **Blueprint** を選ぶ
2. リポジトリ **thinline0924-cell/valence** を選び、**Apply** を押す
3. 表示された URL を開く

設定は `render.yaml` にあります。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面の骨組みと見た目 |
| `js/board.js` | 盤の形(六角形・37マス)と特殊なマス |
| `js/chem.js` | 元素・物質・反応のデータ |
| `js/sim.js` | ルールの本体(結合・完成・反応・連鎖・熱・過熱・核分裂・時間) |
| `js/view.js` | three.js による 3D 表示と演出 |
| `js/hud.js` | スコア・計器・次の原子・開始と結果の画面 |
| `js/audio.js` | 効果音と BGM |
| `js/main.js` | 入り口。上のものをつなぐ |
| `docs/chemistry.md` | 化学の扱い(正しさの方針・単純化・反応の一覧) |
| `docs/ranking.md` | ランキングの設定(Supabase) |
| `js/tutorial.js` | 遊び方の説明(5段階、盤の上で見本が動く) |
| `js/rank.js` / `js/config.js` | ランキングと、その設定 |
| `docs/sound.md` | 用意してほしい効果音と BGM の一覧 |
| `tools/reaction-table.js` | `docs/chemistry.md` の反応の一覧を作る |
| `assets/sound/` | 効果音と BGM。`manifest.json` で場面に割り当てる |
| `tools/selftest.js` | ルールの自動テスト(`npm test`。Node.js が必要) |
| `tools/bundle.py` | 1 枚の HTML にまとめる(試遊用の共有ページを作るとき) |
| `lib/` | three.js(MIT ライセンス) |
