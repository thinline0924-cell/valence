# 効果音と BGM の一覧

音のファイルは `assets/sound/` に置き、`assets/sound/manifest.json` で「鳴らす場面 → ファイル」を割り当てます。割り当てていない場面は、鳴らないだけです。開始画面の「音の確認」から、割り当てた音を1つずつ鳴らせます。

```json
{ "ui": { "file": "se_click.mp3", "gain": 1.2 }, "bgm_main": { "file": "bgm_main.mp3", "loopLength": 126 } }
```

`gain` は音量の倍率、`rate` は再生の速さ(音の高さ)、`trim` は先頭を飛ばす秒数、`loopLength` は BGM のループの長さ(秒)です。

## いま割り当てている音

| 場面 | ファイル | 元のファイル | 手を加えたこと |
|---|---|---|---|
| `ui`(ボタン) | `se_click.mp3` | 1.2秒の高いクリック | 先頭の無音を削り、音量を上げた |
| `tick`(秒読み) | `se_click.mp3` | 同上 | 少し低く鳴らす(`rate` 0.8) |
| `place`(置く) | `se_click.mp3` | 1.2秒の高いクリック | 低く鳴らす(`rate` 0.7)。仮の割り当て |
| `bond`(結合) | `se_tap.mp3` | 同上 | 高く短く鳴らす(`rate` 1.5) |
| `complete`(物質の完成) | `se_complete.mp3` | 1.7秒の澄んだ音 | 先頭の無音を削った |
| `react_s`(小さな反応) | `se_bubble.mp3` | 1.7秒、0.2秒おきに弾む中音 | 先頭の無音を削った。音量 0.55 倍 |
| `react_m`(中くらいの反応) | `se_ignite.mp3` | 0.8秒、低音を含む「ボッ」 | 先頭の無音を削った。音量 0.45 倍 |
| `react_l`(大きな反応) | `se_whoosh.mp3` | 1.4秒、低音と高音の広い音 | 先頭の無音を削った。音量 0.5 倍 |
| `endo`(熱を使う反応) | `se_whoosh.mp3` | 同上 | 高めに小さく(`rate` 1.35) |
| `escape`(気体が抜ける) | `se_whoosh.mp3` | 同上 | さらに高く小さく(`rate` 1.7) |
| `drip`(水の補給) | `se_bubble.mp3` | 同上 | 高めに小さく(`rate` 1.4) |
| `fission`(核分裂) | `se_thump.mp3` | 1.0秒、大きな中低音の衝撃 | 先頭の無音を削った。音量 0.4 倍 |
| `fever_on`(過熱に入る) | `se_chime.mp3` | 3.6秒の連打と余韻 | 先頭の無音を削った |
| `fever_off`(過熱が終わる) | `se_low_fade.mp3` | 1.8秒、低音が静まっていく | 先頭の無音を削った |
| `need_heat`(熱が足りない) | `se_low_pulse.mp3` | 0.8秒、中低音の2つの脈 | 先頭の無音を削った |
| `start`(開始) | `se_boom.mp3` | 0.9秒、低音の強い一打 | 先頭の無音を削った。音量 0.55 倍 |
| `end`(終了) | `se_jingle.mp3` | 4.1秒、中音の短いフレーズ | 先頭の無音を削った |
| `collect`(回収) | `se_pick.mp3` | 1.0秒、明るい中高音がすぐ消える | 先頭の無音を削った |
| `bgm_main` | `bgm_main.mp3` | 「電子の空間」(alaki)2分8秒・120 BPM | そのまま。最後の2秒のフェードを避けて 126 秒でループ |
| `bgm_fever` | `bgm_fever.mp3` | 1分45秒・146 BPM | 320 kbps から 192 kbps に変換。ファイル全体でループ |

**音量のそろえ方**:効果音の大きさ(ラウドネス)を測り、よく鳴る音ほど小さめにそろえている。全体にコンプレッサーをかけ、同じ音は0.09秒以内に重ねず、同時に起きた反応は1つ分だけ鳴らす。

**鳴らさない場面**:`fizzle`(原子が散る)。爆竹のような音が不快とのことで外した。散るときは点滅と縮む動きだけで知らせる

**専用の音があると良くなるもの**:`place`(置く。いまは仮) `bond`(結合) `endo`(熱を使う反応) `escape`(気体が抜ける) `drip`(水の補給)。いまはほかの音の高さを変えて代わりにしている

雰囲気の共通の方向:ガラス・陶器・金属を軽くたたく音、水の音、泡の音など、卓上の実験器具から出そうな音にします。電子音っぽいピコピコした音や、派手な爆発音は避けます。

## 効果音

| ファイル名 | 鳴る場面 | 長さの目安 | 音のイメージ |
|---|---|---|---|
| `place` | 原子のコマを置く | 0.1〜0.2秒 | 陶器のコマを木の卓に置く「コトッ」 |
| `bond` | 原子どうしが結合する | 0.1〜0.2秒 | 細いガラス棒が触れ合う「チッ」 |
| `complete` | 物質が完成する | 0.3〜0.5秒 | 小さく澄んだ音。ガラスの小さなベル |
| `fizzle` | 組み立て途中の原子が散る | 0.3秒 | 乾いた「サラッ」 |
| `react_s` | 小さな反応(100 kJ 未満) | 0.3〜0.5秒 | 泡が弾ける、軽い「ポン」 |
| `react_m` | 中くらいの反応(100〜400 kJ) | 0.5〜0.8秒 | 「ボッ」と火がつく音に、余韻を少し |
| `react_l` | 大きな反応(400 kJ 以上) | 0.8〜1.2秒 | 低めの「ボウッ」。燃焼。爆発ではなく炎 |
| `endo` | 熱を使う反応 | 0.5秒 | 蒸気が抜ける「シュッ」 |
| `collect` | 物質の回収 | 0.3秒 | 軽く上がる音 |
| `escape` | 気体が抜けていく | 0.5秒 | 小さな「シュー」 |
| `drip` | 水の補給 | 0.2秒 | 水滴が落ちる「ピチャ」 |
| `fission` | 核分裂 | 1〜2秒 | 低く深い衝撃と、澄んだ高い余韻。ほかの反応よりはっきり大きく |
| `fever_on` | 過熱に入る | 1〜1.5秒 | 温度が上がっていく、盛り上がる音 |
| `fever_off` | 過熱が終わる | 0.8秒 | 静まっていく音 |
| `need_heat` | 熱が足りない | 0.2秒 | 控えめな低い音 |
| `tick` | 残り10秒の秒読み | 0.1秒 | 時計の針の音 |
| `start` | ゲーム開始 | 0.5〜1秒 | |
| `end` | ゲーム終了 | 1〜2秒 | |
| `ui` | ボタン | 0.05〜0.1秒 | ごく小さなクリック |

連鎖が続くと、反応の音は再生の速さ(音の高さ)を少しずつ上げて鳴らします。そのため、元の音は高すぎないものが合います。

## BGM

| ファイル名 | 鳴る場面 | 長さの目安 | 音のイメージ |
|---|---|---|---|
| `bgm_main` | 通常 | 1〜2分でループ | 静かで、少しリズムのあるアンビエント。考える邪魔をしないもの |
| `bgm_fever` | 過熱中(10秒) | 20〜30秒でループ | `bgm_main` と同じテンポ・調で、音数を増やして熱くしたもの |

BGM は、つなぎ目がわからないループにしてください。
