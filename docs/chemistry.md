# 化学の扱い

「専門家が見ても文句を言われない」ことを目標に、正しさを優先する部分と、遊びやすさのために単純化する部分を分けています。単純化した点は、ゲーム内の図鑑(今後追加)にも書きます。

## 正しさを守るところ

- 反応式は係数まで正しく、原子の数が両辺でそろっている(`npm test` で自動で確かめている)
- 物質の名前は、日本の高校化学で使われる名前に合わせる
- 状態記号 (g)(l)(s)(aq) を付ける
- 平衡反応は ⇌ で書き分ける
- 熱量は、25 °C・1 bar の標準生成エンタルピー(NBS 化学熱力学表)から計算して整数に丸めた値
- 気体の見た目は実際の性質に合わせる
  - 浮く高さ:空気(平均 29 g/mol)より軽い気体ほど高く浮く
  - 色:塩素は黄緑色。そのほかの気体は無色
  - 拡散:気体は隣のマスへ少しずつ動く。速さは 1/√M に比例する(グレアムの法則)

## 単純化しているところ

| 単純化 | 理由 |
|---|---|
| 熱量は式の係数どおりの量(1 mol 単位)で扱い、物質の量は数えない | 盤のコマ1つを「1 mol 分」と見なすため |
| 水溶液のコマは溶媒の水を含んでいるものとする | 溶ける反応のたびに水のコマを1つ使う |
| 食塩水の結晶化は「溶媒の水 1 mol を蒸発させる熱」として +40 kJ とする | 水の蒸発熱 44 kJ/mol と、食塩の溶解熱 +4 kJ/mol から |
| 反応の速さや温度・圧力の条件は、加熱・光・触媒のマスで表す | アンモニアの合成は実際には鉄触媒と高温・高圧が必要。過酸化水素の分解の触媒は二酸化マンガンなど |
| 燃焼は「点火」が必要で、熱ゲージは使わない | 燃焼は活性化エネルギーを越えれば自発的に進むため |
| 原子どうしの結合は、手(原子価)の数だけで決める | イオン結合(NaCl など)も組み立てのときは同じ扱い。完成した姿はイオン結晶として描く |
| 組み立てる物質は、つながり方(どの原子とどの原子が結合しているか)で見分ける | 異性体を区別するため |

## 反応の一覧(18種)

| 反応 | 式 | ΔH (kJ) | 条件 |
|---|---|---|---|
| メタンの燃焼 | CH₄ + 2O₂ → CO₂ + 2H₂O(l) | −890 | 点火 |
| 水素の燃焼 | 2H₂ + O₂ → 2H₂O(l) | −572 | 点火 |
| 過酸化水素の分解 | 2H₂O₂ → 2H₂O + O₂ | −196 | 触媒 |
| 光による塩化水素の生成 | H₂ + Cl₂ → 2HCl | −185 | 光 |
| 塩化アンモニウムの白煙 | NH₃ + HCl → NH₄Cl(s) | −176 | なし |
| 炭酸カルシウムの生成 | Ca(OH)₂ + CO₂ → CaCO₃ + H₂O | −115 | なし |
| アンモニアの合成 | N₂ + 3H₂ → 2NH₃ | −92 | 触媒 |
| 塩化カルシウムが溶ける | CaCl₂(s) → CaCl₂(aq) | −82 | なし |
| 塩化水素が水に溶ける | HCl(g) + H₂O → H₃O⁺ + Cl⁻ | −75 | なし |
| 生石灰と水 | CaO + H₂O → Ca(OH)₂ | −65 | なし |
| 中和 | HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O | −56 | なし |
| 水酸化ナトリウムが溶ける | NaOH(s) → Na⁺ + OH⁻ | −45 | なし |
| アンモニアが水に溶ける | NH₃(g) → NH₃(aq) | −34 | なし |
| 二酸化炭素が水に溶ける | CO₂ + H₂O ⇌ H₂CO₃(aq) | −20 | なし |
| 石灰石と塩酸 | CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂ | −14 | なし |
| 加熱で二酸化炭素が抜ける | H₂CO₃(aq) → H₂O + CO₂ | +20 | 加熱 |
| 水を蒸発させて結晶化 | NaCl(aq) → NaCl(s) | +40 | 加熱 |
| 石灰石の熱分解 | CaCO₃ → CaO + CO₂ | +179 | 加熱 |

石灰の3つの反応(生石灰と水 → 炭酸カルシウムの生成 → 石灰石の熱分解)は、ひと回りすると元に戻る循環です。熱の出入りも、合計がほぼ 0 になります(ヘスの法則)。ゲームでは、同じ連鎖の中で同じ反応をくり返すと得点が半分ずつになります。
