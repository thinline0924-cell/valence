# 化学の扱い

「専門家が見ても文句を言われない」ことを目標に、正しさを優先する部分と、遊びやすさのために単純化する部分を分けています。単純化した点は、ゲーム内の図鑑(今後追加)にも書きます。

## 正しさを守るところ

- 反応式は係数まで正しく、原子の数が両辺でそろっている(`npm test` で自動で確かめている)
- 物質の名前は、日本の高校化学で使われる名前に合わせる
- 状態記号 (g)(l)(s)(aq) を付ける
- 平衡反応は ⇌ で書き分ける
- 熱量は、25 °C・1 bar の標準生成エンタルピー(NBS 化学熱力学表)から計算して整数に丸めた値
- 気体の見た目は実際の性質に合わせる
  - 浮く高さ:空気(平均 29 g/mol)より軽い気体ほど高く浮く
  - 色:塩素は黄緑色。そのほかの気体は無色
  - 拡散:気体は隣のマスへ少しずつ動く。速さは 1/√M に比例する(グレアムの法則)

## 単純化しているところ

| 単純化 | 理由 |
|---|---|
| 熱量は式の係数どおりの量(1 mol 単位)で扱い、物質の量は数えない | 盤のコマ1つを「1 mol 分」と見なすため |
| 水溶液のコマは溶媒の水を含んでいるものとする | 溶ける反応のたびに水のコマを1つ使う |
| 食塩水の結晶化は「溶媒の水 1 mol を蒸発させる熱」として +40 kJ とする | 水の蒸発熱 44 kJ/mol と、食塩の溶解熱 +4 kJ/mol から |
| 反応の速さや温度・圧力の条件は、加熱・光・触媒のマスで表す | アンモニアの合成は実際には鉄触媒と高温・高圧が必要。過酸化水素の分解の触媒は二酸化マンガンなど |
| 燃焼は「点火」が必要で、熱ゲージは使わない。点火は加熱マス、過熱中、または 150 kJ 以上の発熱反応の炎がとなりに来たとき | 燃焼は活性化エネルギーを越えれば自発的に進み、炎は燃え移るため |
| 吸熱でも気体が出る反応(炭酸水素ナトリウムと塩酸)は、条件なしで進み、熱ゲージから熱を奪う | 気体の発生でエントロピーが増え、自然に進むため |
| 盤の水と試薬は、時間とともに補給される | 実験室で試薬を足していくイメージ |
| 組み立ては、つながった原子の組み合わせ(組成)だけで判定し、つなぐ順番やつながり方は問わない | 遊びやすさのため。原子価は元素のコマに点で示し、組成は原子価に合う物質だけを登録している。同じ組成の物質(異性体)は1つだけ登録する |
| イオン結合の物質(NaCl など)も、組み立てのときは同じ扱い | 完成した姿はイオン結晶として描く |
| 完成した物質のとなりに原子を置き、組成がちょうど別の物質になるときは、その物質に変わる(O₂ + O → O₃、H₂ + O → H₂O など) | 組み立ての途中で小さな物質が先にできても、続けて大きな物質を目指せるようにするため |
| 組み立て途中の組成が実在の物質と同じでも、次の原子でもっと大きな物質になれるときは最長2.5秒、なれないときは0.6秒待ってから完成する | 同上 |
| 二酸化硫黄・三酸化硫黄・硝酸・硫酸・一酸化窒素・オゾンなども組成だけで組み立てられる | 硫黄・窒素の原子価が物質によって変わる(超原子価・ラジカル)ため、単純な原子価の数え方には合わないが、組成で判定している |
| 光で進む吸熱反応(オゾンの生成)は、熱ゲージを使わない | 光のエネルギーで進むため |

## 核反応

核反応は化学反応とは別の仕組みで、原子核そのものが変わります。ゲームでは次のように扱います。

- 燃料は二酸化ウラン(UO₂)と二酸化プルトニウム(PuO₂)。実際の原子炉の燃料(MOX 燃料を含む)と同じ化学形
- 核分裂の条件:燃料のペレットが水に接していて、別の燃料に接しているか、となりの核分裂から中性子を受けていること
  - 水は中性子を減速する減速材(軽水炉と同じ)。燃料が集まっていることで臨界の代わりとする
- 核分裂すると、中性子がとなりの燃料に届き、次の核分裂が起こる(核分裂の連鎖反応)
- 水に接していない二酸化ウランが中性子を受けると、プルトニウムに変わる
  - ウラン238が中性子を吸収し、2回のβ崩壊でプルトニウム239になる。実際には数日かかる
- 放出エネルギーは1回あたり約 200 MeV。1 mol あたり約 2×10¹⁰ kJ で、化学反応の数百万倍。ゲームでは熱ゲージが一度に満タンになる
- 核分裂生成物は、代表的な分かれ方を1つだけ式に示す(実際にはさまざまな組み合わせに分かれる)

### 単純化しているところ

| 単純化 | 実際 |
|---|---|
| ウランのコマは、核分裂するウラン235を十分に含む燃料として扱う | 天然ウランのウラン235は約 0.7 %。軽水炉では 3〜5 % に濃縮する |
| 燃料2つと水で核分裂が始まる | 臨界には燃料の量・形・濃縮度・減速材の量が関わる |
| 核分裂で出る気体はクリプトン・キセノンとして盤に出る | 式に示したクリプトン92は短い時間で別の元素に変わる。キセノン134は安定 |
| 使い終わった燃料は15秒間マスをふさいでから消える | 実際の使用済み燃料は、強い放射線と熱を出すため、長い期間の冷却と厳重な管理が必要 |
