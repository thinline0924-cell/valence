# 決まったこと(企画メモ)

話し合いで決めた方針の記録です。変わったら、ここも更新します。

## 全体

- 題名:VALENCE(原子価)
- 化学反応がテーマの 3DCG パズル。スマホの縦画面が主、パソコンでも遊べる
- 遊ぶ人:パズル好きの大人、科学好きの一般の人
- 言語:日本語のみ
- 配布:まず Web(three.js)。完成したらアプリにする(Capacitor などで包む予定)
- 化学は本物志向。専門家が見ても文句を言われないこと。ただし、カジュアルに楽しめる難しさに抑える

## 遊び

- ステージ制ではなく、スコアを稼ぐ遊び。1回2〜3分で、連鎖が続けば5分ほど
- 制限時間のみで終わる(2分30秒)。盤が埋まっても終わらない
- プレイヤーの操作は「原子を置く」だけ。物質は自分では動かさない
- 原子をつなぐ順番は問わない。つながった原子の組み合わせ(組成)が実在の物質と同じになると完成し、物質を象徴する姿に変わる
- もっと大きな物質になれる組み合わせ(たとえば H₂ は H₂O の一部)のときは、0.9秒待ってから完成する。その間に原子を足せば、大きい物質を目指せる
- 元素は反応の回数に応じて増える:最初は8種、5回で Mg・K・F・Br、12回で Al・Si・P・Fe・Cu・Zn・Ag とウラン・プルトニウム
- となり合った物質は、条件がそろうと自動で反応する。生成物がさらに反応すると連鎖になる
- 連鎖が続いている間は、時計が止まる(1回の連鎖で最大8秒)
- それ以上反応する相手がいない生成物は、数秒後に自動で回収される
- 熱の出入りを資源にする:発熱反応で熱がたまり、加熱マスでの吸熱反応に自動で使われる
- 熱が満タンになると「過熱」:一定時間、反応が速くなり、得点は2倍。画面は暖色に寄る(「臨界」は核分裂の用語なので使わない)
- 大きな発熱反応(150 kJ 以上)の炎は、となりの燃えるものに燃え移る
- 最初の一手は見本:加熱マスに Cl を置くと、塩酸 → 中和 → 食塩の結晶化の3連鎖が起こる
- 盤の水と試薬が時間とともに補給され、反応を重ねるほど補給される物質の種類が増える
- 反応を12回起こすと、ウランとプルトニウムが出はじめる。核分裂は組み立ても条件も難しいが、得点と熱は桁違い
- 核分裂は「大きく稼げる切り札」だが、それだけでは稼げない
  - 1ゲームで出るのはウラン3つ・プルトニウム2つまで
  - 核分裂を重ねるほど得点が下がる(1回ごとに 0.6 倍)。連鎖の倍率は2倍まで
  - 使い終わった燃料(核分裂生成物)は15秒間マスをふさぐ
  - 本当の見返りは、熱ゲージが満タンになって過熱が始まること
- 盤が混みすぎないように
  - どことも結合していない原子は7秒、組み立て途中の原子は最後に足してから12秒で散る。散る3秒前から点滅する
  - 反応しない気体は18秒で抜け、反応しない液体・固体は32秒で回収される
  - 水と試薬の補給は、空きマスが十分あるときだけ
  - 空きマスが5つを切ると、いちばん古い物から片付ける
- 物質を1マスずらす操作は入れない
- 反応を見つけやすくする(時間は延ばさない)
  - お題:毎回、まだ見つけていない反応を2つ選んで示す。材料が少なく条件の易しいものから。中心になる物質を盤に置き、黄色い枠で示す。原子から組み立てられない材料は、補給のときに中心のとなりへ落とす。達成すると +500
  - 手がかり:物質ができたとき、その物質が関わる未発見の反応の相手と条件を一瞬示す(5秒に1回まで)
  - 図鑑:革装の辞書の体裁。章ごとの爪かけ、項目番号、見出し語。見つけた反応は式・熱・条件・解説、未発見の反応は材料と条件だけを示し「未収録」の印を押す
- 原子の出方は、組み立て中の分子に合うものを少し多めに配る(重み付き)
- イオン・塩も扱う
