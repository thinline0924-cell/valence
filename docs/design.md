## 全体

- 題名:VALENCE(原子価)
- 化学反応がテーマの 3DCG パズル。スマホの縦画面が主、パソコンでも遊べる
- 遊ぶ人:パズル好きの大人、科学好きの一般の人
- 言語:日本語のみ
- 配布:まず Web(three.js)。完成したらアプリにする(Capacitor などで包む予定)
- 化学は本物志向。専門家が見ても文句を言われないこと。ただし、カジュアルに楽しめる難しさに抑える

## 遊び

- ステージ制ではなく、スコアを稼ぐ遊び。1回2〜3分で、連鎖が続けば5分ほど
- 制限時間のみで終わる(2分30秒)。盤が埋まっても終わらない
- プレイヤーの操作は「原子を置く」だけ。物質は自分では動かさない
- 原子は、手(原子価)の数だけ自動で結合する
- 手がすべて埋まって実在の物質になると完成し、物質を象徴する姿に変わる
- となり合った物質は、条件がそろうと自動で反応する。生成物がさらに反応すると連鎖になる
- 連鎖が続いている間は、時計が止まる(1回の連鎖で最大8秒)
- それ以上反応する相手がいない生成物は、数秒後に自動で回収される
- 熱の出入りを資源にする:発熱反応で熱がたまり、加熱マスでの吸熱反応に自動で使われる
- 熱が満タンになると「過熱」:一定時間、反応が速くなり、得点は2倍。画面は暖色に寄る(「臨界」は核分裂の用語なので使わない)
- 大きな発熱反応(150 kJ 以上)の炎は、となりの燃えるものに燃え移る
- 最初の一手は見本:加熱マスに Cl を置くと、塩酸 → 中和 → 食塩の結晶化の3連鎖が起こる
- 盤の水と試薬が時間とともに補給され、反応を重ねるほど補給される物質の種類が増える
- 反応を12回起こすと、ウランとプルトニウムが出はじめる。核分裂は組み立ても条件も難しいが、得点と熱は桁違い
- 物質を1マスずらす操作は入れない
- 原子の出方は、組み立て中の分子に合うものを少し多めに配る(重み付き)
- イオン・塩も扱う
